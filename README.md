# PDDikti Excel Converter (Web)

Konversi format Excel PDDikti dari format **long** (satu baris per prodi per semester) ke format **wide/pivot** (satu baris per prodi, semester jadi kolom), dengan tambahan kolom **Nama Perguruan Tinggi**.

## Fitur
- 📤 Upload file Excel hasil scraping PDDikti
- 🏫 Input nama Perguruan Tinggi (atau otomatis dari sheet Info)
- 🔄 Konversi format long → wide (pivot) di browser
- 📊 Preview tabel hasil konversi
- ⬇️ Download hasil sebagai `.xlsx`
- 🔒 100% client-side — data tidak dikirim ke server manapun

## Deploy ke Vercel
Lihat instruksi di bawah atau jalankan `vercel deploy`.
